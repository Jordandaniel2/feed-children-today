# FEED the CHILDREN TODAY

A modern, responsive charity website built with React, TypeScript, and Tailwind CSS.

## Features

- 🎨 Beautiful warm & hopeful design system
- 📱 Fully responsive mobile-first layout
- 💰 Multiple donation methods (Gift Cards, Apple Pay, Crypto)
- 📊 Animated impact statistics
- ⚡ Lightning-fast performance with Vite
- ♿ Accessible components

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```

## Design System

- **Primary Color**: Orange-Red (hsl 18 90% 50%)
- **Secondary Color**: Warm Yellow (hsl 42 95% 55%)
- **Accent Color**: Deep Amber (hsl 30 85% 45%)
- **Background**: Warm Cream (hsl 36 30% 97%)
- **Foreground**: Dark Warm Brown (hsl 20 30% 15%)
