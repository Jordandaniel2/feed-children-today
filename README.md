# FEED the CHILDREN TODAY

A modern, responsive charity website built with React, TypeScript, and Tailwind CSS. Founded by Jordan Daniel to end child hunger in the USA through innovative donation methods including gift cards, Apple Pay, and cryptocurrencies.

## 🎯 Mission

Every child deserves a full plate. FEED the CHILDREN TODAY is dedicated to eliminating child hunger across the United States through accessible, modern donation methods that make it easy for compassionate people to make a real difference.

## ✨ Features

- 🎨 Beautiful warm & hopeful design system
- 📱 Fully responsive mobile-first layout
- 💳 Multiple donation methods:
  - Gift Cards (Apple, Amazon, Google Play)
  - Apple Pay
  - Cryptocurrency (Bitcoin, Ethereum, USDC)
- 📊 Animated impact statistics & progress tracking
- ⚡ Lightning-fast performance with Vite
- ♿ Accessible components
- 🎭 Smooth animations & transitions

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/Jordandaniel2/feed-children-today.git
cd feed-children-today
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
```

### Preview Build

```bash
npm run preview
```

## 🎨 Design System

### Color Palette

- **Primary**: Orange-Red `hsl(18 90% 50%)`
- **Primary Foreground**: White `hsl(0 0% 100%)`
- **Secondary**: Warm Yellow `hsl(42 95% 55%)`
- **Accent**: Deep Amber `hsl(30 85% 45%)`
- **Background**: Warm Cream `hsl(36 30% 97%)`
- **Foreground**: Dark Warm Brown `hsl(20 30% 15%)`
- **Muted**: Soft Peach `hsl(30 20% 90%)`

### Animations

- `fade-up` - Fade and slide up animation
- `pulse-warm` - Warm pulsing effect
- `float` - Floating animation
